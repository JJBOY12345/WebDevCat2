# Demo Users

These accounts are created automatically by the User Service when it starts for the first time.

| Name | Email | Password | Role |
|---|---|---|---|
| Store Admin | `admin@shop.local` | `admin123` | `ADMIN` |
| Demo Customer | `demo@shop.local` | `demo123` | `CUSTOMER` |
| Student Customer | `student@shop.local` | `student123` | `CUSTOMER` |

Customers can also create additional accounts through the registration screen. These are local demonstration accounts only and must not be used in a real deployment.
